# ROADMAP.md

## Roadmap

The terrain-lock project aims to develop a GPS jamming-resistant navigation system for drones, utilizing alternative navigation methods such as terrain recognition or inertial measurement. Below is a high-level roadmap outlining the key milestones for the project.

### MVP Milestone (Must-Have for Launch)

The MVP milestone focuses on delivering a basic, functional navigation system that can operate in GPS-denied environments. The following features are critical for the MVP:

#### MVP Critical Features

* **Terrain Recognition**: Implement a basic terrain recognition algorithm using onboard sensors (e.g., cameras, lidar) to estimate the drone's position and orientation.
* **Inertial Measurement**: Integrate an inertial measurement unit (IMU) to provide accurate measurements of the drone's acceleration, roll, pitch, and yaw.
* **Basic Navigation**: Develop a simple navigation algorithm that uses terrain recognition and IMU data to control the drone's movement.

#### MVP Non-Critical Features

* **Sensor Fusion**: Implement sensor fusion techniques to combine data from multiple sensors (e.g., cameras, lidar, IMU) to improve navigation accuracy.
* **Real-Time Processing**: Optimize the navigation algorithm for real-time processing to ensure smooth and responsive drone control.

### v1 Phase

The v1 phase focuses on enhancing the navigation system with additional features and improving overall performance.

#### v1 Themes

* **Advanced Terrain Recognition**: Develop more advanced terrain recognition algorithms using machine learning techniques and high-resolution sensors.
* **Improved Sensor Fusion**: Enhance sensor fusion techniques to better handle sensor noise and variability.
* **Enhanced Navigation**: Develop more sophisticated navigation algorithms that take into account additional factors such as wind, air density, and drone dynamics.

#### v1 Critical Features

* **Advanced Terrain Recognition**: Implement a machine learning-based terrain recognition algorithm that can accurately identify terrain features and obstacles.
* **Improved Sensor Fusion**: Develop a robust sensor fusion algorithm that can handle sensor noise and variability.

### v2 Phase

The v2 phase focuses on integrating terrain-lock with other drone systems and expanding its capabilities.

#### v2 Themes

* **Integration with Other Drone Systems**: Integrate terrain-lock with other drone systems such as autopilot, communication, and payload management.
* **Expanded Capabilities**: Develop new features and capabilities such as terrain mapping, obstacle avoidance, and autonomous flight planning.

#### v2 Critical Features

* **Integration with Autopilot**: Integrate terrain-lock with a commercial autopilot system to enable seamless navigation and control.
* **Terrain Mapping**: Develop a terrain mapping feature that can create detailed maps of the environment for future navigation and planning.

## Next Steps

The next steps for the terrain-lock project include:

* Finalizing the MVP milestone and conducting thorough testing and validation.
* Developing the v1 phase features and integrating them into the navigation system.
* Planning and executing the v2 phase features and integration with other drone systems.

By following this roadmap, we aim to deliver a robust and reliable GPS jamming-resistant navigation system for drones that can operate in a variety of environments.
